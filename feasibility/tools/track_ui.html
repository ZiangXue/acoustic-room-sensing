Order of things

  1. Press Start recording here, before the phones.
  2. Start the Voice Memos recording on all three phones.
  3. Wait for the green READY (about 6 s). The camera only sends a full video frame every ~4 s, so the start of a recording is unusable.
  4. Clap 3 times at the center sticker, hands in view of the camera.
  5. ... session ... then 3 claps again, stop the phones, then press Stop.
