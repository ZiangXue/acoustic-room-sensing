Scripts from the first calibration attempts, kept for reference. They are not maintained and
read their inputs from the old layout (`data/`, `measurements/` relative to `feasibility/`), so
they will not run as-is. `tools/calib.py` supersedes `fit_floor.py` and `extrapolate_grid.py`;
`annotate_sample.py` and `rug_corners.py` drew the landmark overlays, with hand-picked pixels.
Their old image outputs are in `../output/legacy/`.
